# 🎁 FreeStuff Finder

A hand-curated, single-page hub of **software giveaways, free trials, free AI tools, and cloud free tiers** — sourced from across the internet.

🔗 **Live demo:** `https://nasmygpt-lgtm.github.io/freesoftware/` *(after enabling GitHub Pages — see below)*

---

## ✨ Features

- 🔍 **Live search** — filter across every offer instantly as you type
- 🏷️ **Category filters** — one-click filtering by type
- 📇 **33 curated offers**, each with a description, the actual offer terms, and a direct link
- 🌙 **Modern dark, responsive design** — works on mobile and desktop
- 📦 **Zero dependencies** — a single self-contained `index.html`, no build step

## 🚀 Run locally

Just open `index.html` in any browser — no server or install required.

## 🌐 Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository
2. Under **Source**, choose **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`, then **Save**
4. Your site goes live at `https://nasmygpt-lgtm.github.io/freesoftware/` within ~1 minute
