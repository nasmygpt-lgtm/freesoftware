This is **not** a list of generic "free tiers" — every entry is a real, limited-time offer with its terms: **what you get, who qualifies, and when it expires.**

## 🚀 Run locally

Just open `index.html` in any browser — no server or install required.

## 🌐 Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository
2. Under **Source**, choose **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`, then **Save**
4. Your site goes live at `https://nasmygpt-lgtm.github.io/freesoftware/` within ~1–2 minutes

## ⚠️ Disclaimer

Offers change **very** fast — especially Indian telecom plans (prices, validity, bundled apps) and VPN "free trials" (often really 30-day money-back guarantees).
